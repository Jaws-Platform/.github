The `Jaws-Platform` organization's profile repository. It is part of
[Jaws](https://github.com/Jaws-Platform/jaws).

- [`profile/README.md`](profile/README.md) is the page
  [github.com/Jaws-Platform](https://github.com/Jaws-Platform) shows: what
  Jaws is, how a project uses it, and every repository and GitHub App in the
  organization. Update it when a repository or an App is added or retired.
- Because this is the organization's public `.github` repository, GitHub uses
  its community health files (`CONTRIBUTING.md` and the pull request
  templates in `.github/`) as defaults for any organization repository that
  has none of its own. Every Jaws repository ships its own, as the
  conventions require.

The banner, and the header every Jaws README opens with, come from
[`jaws-branding`](https://github.com/Jaws-Platform/jaws-branding#readme-headers).

Contribution rules are in [CONTRIBUTING.md](CONTRIBUTING.md); the rules for
coding agents are in [AGENTS.md](AGENTS.md).
